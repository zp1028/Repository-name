# 彩票 AI 数据分析助手（Streamlit 多彩种版）

支持三种彩种的历史数据统计与可视化分析。

> ⚠️ **重要声明**  
> 彩票开奖完全随机，历史数据**无法预测**未来。  
> 本工具仅用于数据科学学习与娱乐，请理性购彩。

## 支持彩种

| 彩种 | 数据特点 | 主要分析 |
|------|----------|----------|
| **双色球** | 红6+蓝1，周开3次 | 频率、遗漏、和值、奇偶 |
| **快乐8（官方）** | 从1-80开20个，日开 | 1-80频率、遗漏、和值、奇偶/大小分布 |
| **极速飞艇（PK10）** | 10个名次(1-10)，高频 | 各名次热力、冠军频率、冠亚和、龙虎 |

## 快速启动

```bash
cd lottery_ssq_app
pip install -r requirements.txt
streamlit run app.py
```

浏览器打开 `http://localhost:8501`，在侧边栏切换彩种即可。

## 数据来源

- 双色球 / 快乐8：`data.17500.cn` 公开历史文本（自动缓存到 `data/`）
- 极速飞艇：`api.api68.com` 第三方接口（按天拉取最近几天数据）

极速类高频彩种无官方长期免费全量接口，本工具仅加载最近若干天数据用于算法演示。

## 功能说明

### 双色球
- 红球/蓝球频率柱状图 + 热冷号
- 当前遗漏
- 和值走势
- 历史查询与 CSV 下载

### 快乐8
- 1-80 全号频率
- 当前遗漏（最长遗漏排名）
- 20码和值走势、奇数个数分布、大号(41-80)个数分布

### 极速飞艇
- 10个名次 × 1-10 号码出现热力图
- 冠军号码频率、冠亚和分布
- 简单龙虎（冠军vs第十）、冠亚和大小
